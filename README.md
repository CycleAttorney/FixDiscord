> Один и тот же инструмент способны применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляет их и помещает в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете настройку исключений, предпочтительно добавить исключение; при отсутствии уверенности рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и укажите URL вручную. Например: `https://dns.google/dns-query` (Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/CycleAttorney/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для запуска стратегии вместе с системой выберите **`service.bat`** -> `Install Service` -> нужная стратегия

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — показать состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  После смены режима нужно перезапустить стратегию.  
  Текущее состояние (включено/выключено) отображается в скобках.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается состояние:
    - `none` — IP-адреса не проверяются
    - `loaded` — адрес проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** — включить или выключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить текущий фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы
  - **`Run Tests`** — проверить стратегии с помощью специальной утилиты:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe. Его можно найти на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/CycleAttorney/zapret-discord-youtube/issues/522)

### Не работает ни одна стратегия
- Откройте командную строку с правами администратора
- По очереди выполните команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если имеющийся hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте содержимое открывшегося блокнота целиком
  - В появившейся папке откройте файл `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный блок
  - Сохраните файл и проверьте соединение. Если проблема осталась, убедитесь, что изменения действительно записались.

#### Результат не гарантируется. Если веб-версия не заработала, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/CycleAttorney/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или снова перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который некоторое время успешно работал, может перестать помогать после его обнаружения.
> В репозитории собрано много стратегий обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из существующих и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` запустите `Run Diagnostics` и убедитесь, что проверка не показывает ошибок

- Проверьте, внесён ли адрес нужного ресурса в списки доменов или IP-адресов

- Попробуйте другие варианты, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/CycleAttorney/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце подтвердите `Y`
- Удалите старую папку zapret
- Загрузите последнюю версию со [страницы релизов](https://github.com/CycleAttorney/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Щёлкните по архиву правой кнопкой, откройте свойства и, если внизу справа есть пункт разблокировки, отметьте его, нажмите «Применить», затем «ОК»
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов в пути
- По очереди запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если вариант не подходит, закройте программу через значок замка на панели задач и выберите другую стратегию
- После поиска рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### На Windows 7 требуется цифровая подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройки [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать
- См. также [#251](https://github.com/CycleAttorney/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord и результат очистки
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если браузер тоже не подключается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/CycleAttorney/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/CycleAttorney/tg-ws-proxy)
- Также можно использовать бесплатные MTProto-прокси из интернета

### Не запускаются игры или нет подключения

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте универсальный порядок действий:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если это не помогло, создайте обсуждение в разделе [Discussions](https://github.com/CycleAttorney/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Опишите её [в issue](https://github.com/CycleAttorney/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Нужные адреса можно добавить в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены будут учитываться автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить (например, когда сеть присутствует в `ipset-all.txt`, но отдельный домен фильтровать не следует)
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети-исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
